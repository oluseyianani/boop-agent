# QA lint + testing/scaling

## Pre-delivery lint (fix every hit before shipping a script)

- [ ] **Rambling hook** — first words call out the audience, not the creator's life/morning/weekend.
- [ ] **Choppy phrasing** — no stacked two-word fragments; sentences connect and breathe.
- [ ] **Jargon mechanism** — a 12-year-old understands every word; else replace.
- [ ] **Analogy present** — there is exactly one tactile `"less like ___ / more like ___"` line, and it is intact.
- [ ] **Veering CTA** — used a soft-CTA-bank close, not an invented structure.
- [ ] **Static b-roll** — every shot has motion; no locked-off shots, no still talking heads.
- [ ] **Mismatched visuals** — every visual matches the exact word the VO says at that moment.
- [ ] **Decorative b-roll** — no cuts to furniture/art/interior unrelated to the VO. No cinematic establishing shots.
- [ ] **Over-formatted output** — single-prompt deliverable is a clean prose block (no headers/tables/notes). Chunked uses only the per-chunk fields.
- [ ] **Phone in hand when not needed** — phone is off-camera unless selfie-style is called for.
- [ ] **Frozen pose** — no hands in pockets/behind back; natural two-hand gestures.
- [ ] **Product shown too early** — product/`@asset` does not appear until the VO names it (NO/YES/NO or NO/NO/NO/YES/NO).
- [ ] **Wrong condition on creator** — the present-tense creator shows the *after*; no visible blemish/damage/stress the product fixes.
- [ ] **Visible residue** (physical) / **fake UI** (app) — application leaves only realistic residual; app shows the real reference element, no invented interface.
- [ ] **Voice rules** — no em dashes, no bolding in VO; AI-mispronounced words swapped or phonetically noted; brand pronunciation locked if spoken.

## Test set before scaling spend

Build **6–10 scripts** first, covering at minimum: all five variation types; 2–3 demographic profiles; 2–3 hook frameworks; both formats (mid-funnel + full stack); at least one mass-desire deep-pain-point angle.

## What to watch

- Watch time & completion rate (not just CTR).
- Cost per click **against creative angle**.
- **Comment sentiment — are viewers saying the analogy back to each other?** That is the signal the script is working.
- Which demographic the algorithm serves each script to.

## Kill vs scale

- **KILL** if watch time drops in the first 3 seconds (hook failed), or viewers watch but don't click (payoff/CTA weak).
- **SCALE** if comments quote the analogy or payoff line back (product-language fit). Then write hook variations on the winner *before* fatigue sets in.
- **Fatigue defense:** rotate demographics and settings. Same script + different creator/setting can extend a winning angle by weeks.
